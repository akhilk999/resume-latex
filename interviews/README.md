# Interviews

Cross-cutting interview preparation distilled from `experiences/*_INTERVIEW_GUIDE.md`.

**Do not invent** ownership, metrics, or stories here. Link back to experience folders for evidence.

**Priority:** Populate after experience docs are solid, and as [`job_descriptions/`](../job_descriptions/) clarifies which stories matter for target roles. Experience-level guides remain the detailed source; this folder is for reusable cross-experience distillation.

## How to populate

1. Prefer stories already written in `experiences/<name>/*_INTERVIEW_GUIDE.md`.
2. Copy the strongest ones here with a link to the source experience.
3. Tag by target role (Backend, AI, Robotics, Product) when useful for JD matching.
4. If a story is weak or upcoming-only (e.g. CSCE 120 not started), leave it out or mark clearly.
