## Engineering / teaching challenges (confirmed)

1. **Uneven PT coordination** — some PTs irresponsible; resolved by direct conversation to rebalance manual work.  
2. **Grading throughput** — created rubrics when missing; graded against key criteria instead of every line.  
3. **Environment setup** — helping students install Python and packages locally.  
4. **PHYS Jetson connectivity** — Linux VM connection and copying outputs to personal (esp. Mac) machines; improved with practice but not “systems eng.”  
5. **Teaching across experience levels** — main lesson: adapt explanations; peers range from lifelong coders to complete beginners; metaphors (incl. pop-culture) must fit the audience or they fail.

---

## Debugging / mentoring story (confirmed)

**Best story:** Teaching students to debug with **manual print statements** to locate failure points, then **dry-run** their code to understand each step — building transferable debugging skill rather than only fixing the assignment for them.

Common ENGR issues: **Python install/packages**, then **syntax errors**.
